1. Who we are

Shorts AI Studio ("the app") is a desktop application that runs on the user's own Windows computer. The app does not operate its own server and does not collect user data on any server of ours.

Shorts AI Studio(이하 "프로그램")는 사용자의 Windows 컴퓨터에서 실행되는 데스크톱 프로그램입니다. 별도의 서버를 운영하지 않으며, 사용자 정보를 저희 서버로 수집하지 않습니다.

2. Information the app handles

  • TikTok account: with the user's permission, basic profile information (user.info.basic, e.g. display name) to show which account is connected, and permission to upload videos as drafts (video.upload).
  • Login tokens: TikTok and YouTube access/refresh tokens are saved only in a local folder on the user's computer.
  • Videos, audio and subtitles that the user selects are processed on the user's computer.
  • TikTok 계정: 사용자가 허락한 경우, 연결된 계정을 표시하기 위한 기본 프로필 정보(user.info.basic, 예: 표시 이름)와 영상을 초안으로 올리는 권한(video.upload)
  • 로그인 토큰: TikTok·YouTube 토큰은 사용자 컴퓨터의 로컬 폴더에만 저장됩니다.
  • 사용자가 고른 영상·음성·자막은 사용자 컴퓨터에서 처리됩니다.

3. Third-party services

When the user chooses to use them with their own API keys, parts of the video (sample frames, audio or text) are sent to AI and speech services such as Anthropic (Claude), Google (Gemini), OpenAI, Groq and Typecast, only to generate scripts, subtitles and narration. Completed videos are sent to TikTok or YouTube only when the user presses the upload button. Each service handles data under its own privacy policy.

사용자가 본인의 API 키로 선택해 사용하는 경우, 대본·자막·나레이션을 만들기 위해 영상의 일부(장면 이미지, 음성, 글)가 Anthropic(Claude), Google(Gemini), OpenAI, Groq, Typecast 등 AI·음성 서비스로 전송됩니다. 완성 영상은 사용자가 업로드 버튼을 누를 때에만 TikTok 또는 YouTube로 전송됩니다. 각 서비스의 데이터 처리는 해당 서비스의 개인정보처리방침을 따릅니다.

4. Sharing and selling

We do not sell, rent or share user information with anyone.

사용자 정보를 판매·대여하거나 다른 곳에 제공하지 않습니다.

5. Retention and deletion

All data stays on the user's computer until the user deletes it. To remove TikTok access, press "Disconnect" in the app or delete the app's data folder, and revoke the app in TikTok (Settings and privacy → Security → Manage app permissions).

모든 데이터는 사용자가 지우기 전까지 사용자 컴퓨터에만 남습니다. TikTok 연결을 해제하려면 프로그램에서 '연결 해제'를 누르거나 프로그램의 data 폴더를 지우고, TikTok 앱(설정 및 개인정보 → 보안 → 앱 권한 관리)에서 권한을 취소하세요.

6. Children

The app is not intended for children under 13 (or the minimum age in the user's country).

이 프로그램은 만 13세 미만(또는 해당 국가의 최소 연령 미만) 어린이를 대상으로 하지 않습니다.
