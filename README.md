# Shorts AI Studio 웹사이트 (TikTok 개발자 등록용)

1. 모든 파일에서 `YOUR_EMAIL@example.com`을 본인 이메일로 바꾸세요(메모장 → 편집 → 바꾸기 → 모두 바꾸기).
2. GitHub 저장소(Public)에 이 폴더의 파일을 모두 올립니다.
3. Settings → Pages → Branch: main / (root) → Save
4. TikTok 개발자 페이지:
   - Web/Desktop URL: https://아이디.github.io/저장소이름/
   - Privacy Policy URL: https://아이디.github.io/저장소이름/privacy.html
   - Terms of Service URL: https://아이디.github.io/저장소이름/terms.html
5. URL 인증(URL prefix)에서 받은 서명 파일(.txt)도 이 저장소 맨 위에 올린 뒤 Verify.
